# 동아출판 CI 색과 로고

## 1. CI에서 뽑은 색

동아출판 CI 그림에서 그대로 잰 두 색이다.

| 이름 | 값 | CI에서 | 쓰는 곳 |
|---|---|---|---|
| CI 빨강 `--donga-red` | `#ec1940` | 오른쪽 위 반원(ㅇ) | 로고, 브랜드 그래픽. 버튼과 글자에는 쓰지 않는다 |
| CI 먹 `--donga-ink` | `#333333` | 왼쪽 ㄷ과 "동아출판" 글자 | 로고(라이트), 보조색 |

CI 빨강은 흰 바탕 위 대비가 4.39라 흰 글자를 얹으면 4.5에 조금 모자란다. 그래서 버튼과 선택 상태에 쓰는 주색은 OKLCH 밝기만 조금 내린 값으로 정했다. 색상과 채도는 CI 그대로다.

## 2. 고정 테마색

사용자가 따로 말하지 않는 한 바꾸지 않는다. 당토 디자인의 "테마색 고르기" 단계는 건너뛴다.

| 역할 | 라이트 | 위 글자 | 대비 | 다크 | 위 글자 | 대비 |
|---|---|---|---|---|---|---|
| 주색 `--accent` | `#d4153a` | `#ffffff` | 5.3 | `#ff5a72` | `#2a0610` | 6.2 |
| 보조색 `--second` | `#333333` (CI 먹) | | 흰 바탕 12.6 | `#e8e8e8` | | 어두운 바탕 15.1 |
| 셋째 색 | 없음 | | | | | |

- **주색(동아 빨강):** 채운 주요 버튼(화면마다 하나), 선택 상태, 진행 막대, 그래프의 핵심 계열 하나.
- **보조색(동아 먹):** 머리 띠, 로고, 차트 둘째 계열. 버튼, 링크, 선택 상태에는 쓰지 않는다.
- 셋째 색은 두지 않는다. CI가 두 색이라 색을 더하면 브랜드가 흐려진다. 배지에 색이 필요하면 상태색이나 회색을 쓴다.
- 큰 면을 빨강으로 칠하지 않는다. 빨강은 "누르는 곳"과 "고른 것"의 신호다. 면이 넓어지면 신호가 사라지고 화면이 경고처럼 보인다.

## 3. 빨강 주색과 위험색 구분

주색이 빨강이라 오류와 헷갈리기 쉽다. 그래서

- 위험색 `--critical`은 주황 쪽으로 옮긴 빨강(라이트 `#b42318`, 다크 `#ff8a5c`)이다.
- 오류와 위험 표시는 **반드시 아이콘(느낌표 삼각형 등)과 문구를 함께** 쓴다. 색만으로 오류를 알리지 않는다.
- 정답, 오답처럼 맞고 틀림을 보여 줄 때는 성공색과 위험색을 쓰고, 주색 빨강으로 오답을 표시하지 않는다.
- 되돌릴 수 없는 행동(삭제 등) 버튼은 위험색 글자의 회색 바탕 버튼으로 두고, 확인 대화상자 안에서만 위험색 채움 버튼을 쓴다. 이때 그 대화상자에는 주색 채움 버튼을 같이 두지 않는다.
- 주의색은 노란 쪽(라이트 `#8a5a00`, 다크 `#f0b44a`)으로 옮겨 위험색과 거리를 둔다.

## 4. 로고 파일

| 파일 | 쓰는 곳 |
|---|---|
| `assets/logo/donga-ci.svg` | 밝은 바탕. 먹 + 빨강 |
| `assets/logo/donga-ci-dark.svg` | 어두운 바탕. ㄷ과 글자가 밝은 회색 `#eceef1`, 빨강은 그대로 |
| `assets/logo/logo-open.snippet.html` | 화면 안에 넣는 로고(테마를 따라 색이 바뀜)와 열림 애니메이션 |

SVG는 제공받은 CI 그림을 따라 그린 것이다. 회사가 준 원본 로고 파일이 있으면 그것을 먼저 쓴다. 로고 모양, 비율, 색을 바꾸지 않는다(늘이기, 기울이기, 그림자, 테두리, 다른 색 금지). 로고 둘레에 ㅇ 반원 높이의 절반 이상 여백을 둔다.

**어디에 넣나**
- 독립 웹 도구, 시연 자료, 시작 화면, 표지: 넣는다.
- 두클래스에 올리는 자료: 플랫폼 뷰어가 이미 머리 띠와 로고를 보여 준다. 콘텐츠 안에 로고를 다시 넣지 않는다. 공식 로고와 저작권 문구는 담당자에게 받은 것만 쓴다(`douclass.md`).
- 화면 안 머리 띠에는 작게(높이 24~32px) 한 번만. 한 화면에 로고를 두 번 넣지 않는다.

## 5. 열림 애니메이션

CI의 ㄷ과 ㅇ은 높이가 같고, ㄷ의 열린 오른쪽과 ㅇ 반원의 곧은 왼쪽이 맞닿으면 D 하나가 된다. 애니메이션은 이 D에서 시작한다.

1. 0~0.2초: 가운데에 붙은 D가 나타난다.
2. 0.5~1.2초: ㄷ은 왼쪽 아래로, ㅇ은 오른쪽 위로 벌어져 CI 자리로 간다.
3. 같은 시간에 "동아출판" 글자가 ㄷ의 오른쪽 끝과 ㅇ의 왼쪽 끝을 그대로 따라 드러난다. 글자는 ㄷ, ㅇ 아래에 그려져 둘 뒤에서 나오고, 아래쪽도 내려가는 ㄷ의 밑변을 따라가서 붙은 D 밖으로 삐져나오지 않는다. 그래서 벌어지는 동안 둘 사이에 하얀 빈칸이 생기지 않는다.

`assets/logo/logo-open-frames.png`에 시간별 모습이 있다.

**쓰는 규칙** (당토 디자인의 "장식 애니메이션 금지"에 대한 유일한 예외)
- 시작 화면, 표지, 불러오는 동안처럼 **화면마다 한 번**만 재생한다. 되풀이하지 않는다.
- 1.5초를 넘기지 않고, 끝나기를 기다리게 하지 않는다. 시작 버튼은 처음부터 누를 수 있어야 한다.
- 움직임 줄이기 설정이면 벌어지는 움직임 없이 0.4초 동안 나타나기만 한다(조각에 들어 있음). 윈도우의 "애니메이션 효과"를 끈 PC도 여기에 해당한다.
- 다시 보여 줄 때는 `is-open` 클래스를 뺐다가 다음 프레임에 다시 넣는다.
- 애니메이션 시간과 곡선을 바꾸지 않는다. 브랜드 움직임은 어디서나 같아야 한다.

## 6. 브랜드 개성 다이얼

`data-personality="brand"`를 켜면 모서리가 모두 0이 된다. CI의 ㄷ이 각진 모양이라 각진 모서리가 브랜드와 어울린다. 제목 서체는 바꾸지 않는다(CI 글자표를 흉내 내는 서체를 쓰지 않는다).
