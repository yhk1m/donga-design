# 토큰 값

> **동아 디자인에서는:** 색 값은 CI에서 만든 값으로 고정되어 있다(`brand.md`). 이 문서의 테마색 설명 중 "고르기"는 해당하지 않는다. 변수는 `:root`가 아니라 `.dc-content` 래퍼에 들어 있다.

모든 값은 `assets/tokens.css`에 CSS 변수로 들어 있다. 이 문서는 값의 뜻과 쓰는 곳을 설명한다. 괄호 안은 근거가 된 회사다.

## 색

### 회색 10단계
남색 기운이 살짝 도는 차가운 회색이다. 순수 회색(#888)보다 화면이 맑아 보인다. (토스 #191f28, 당근 #1a1c20, 쏘카 #141A24)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| gray-50 | #f8f9fb | 아주 연한 상자 바탕(인용, 메시지) |
| gray-100 | #f1f3f6 | 화면 바탕, 회색 버튼, 선택한 줄 |
| gray-200 | #e4e7ec | 진행 막대 빈 칸, 비활성 바탕 |
| gray-300 | #d0d5dd | 빈 체크 표시 |
| gray-400 | #a9b1bd | 비활성 글자 |
| gray-500 | #868f9c | 장식 아이콘(화살표). 글자에 쓰지 않음 |
| gray-600 | #646d7a | 보조 글(흰 바탕 대비 5.2) |
| gray-700 | #4a5260 | 보통 글 |
| gray-800 | #2f3640 | 진한 글 보조 |
| gray-900 | #1a1e25 | 제목, 가장 진한 글 |

### 역할 색
색은 이름이 아니라 역할로 쓴다. 코드에 `#3182f6`을 직접 쓰지 말고 `var(--accent)`를 쓴다. (모든 시스템 공통)

| 역할 | 토큰 |
|---|---|
| 바탕 / 흰 면 / 떠 있는 면 | `--bg` / `--surface` / `--surface-raised` |
| 글자 4단계 | `--text-strong` / `--text` / `--text-muted` / `--text-disabled` |
| 선 | `--line`(투명 검정 8%), `--line-strong`(16%) |
| 주색 | `--accent`, `--on-accent`, `--accent-press`, `--accent-weak`, `--accent-text` |
| 상태 | `--positive`, `--warning`, `--critical`, `--info`와 각각의 `-weak` |
| 포커스 | `--focus` |

선은 진한 회색 실선이 아니라 옅은 투명 검정이다. 바탕색이 바뀌어도 자연스럽다. (채널톡 #00000014)

### 다크 모드
| 층 | 값 |
|---|---|
| 바탕 | #121418 |
| 흰 면 대신 | #1b1e24 |
| 떠 있는 면 | #252930 |
| 글자 | #eef0f3 / #c4cad3 / #8e97a4 / #5d6571 |

- 라이트를 뒤집지 않고 따로 정한 값이다. (토스, 당근, 쏘카)
- 위층일수록 밝다. 그림자는 거의 쓰지 않는다.
- 상태색과 주색은 다크에서 더 밝은 값으로 바뀐다.

## 글자

| 토큰 | 편안 | 촘촘 | 쓰는 곳 |
|---|---|---|---|
| `--fs-title-l` | 30 | 22 | 화면 큰 제목(한 화면에 하나) |
| `--fs-title` | 24 | 18 | 질문형 제목, 상세 제목 |
| `--fs-title-s` | 20 | 16 | 묶음 제목, 시트 제목 |
| `--fs-body-lg` | 17 | 14 | 목록 제목, 주요 버튼 |
| `--fs-body` | 16 | 14 | 본문 |
| `--fs-small` | 14 | 13 | 보조 글 |
| `--fs-caption` | 13 | 12 | 표 머리, 시각, 각주 |

- 줄 높이: 본문 1.5, 제목 1.35. (토스 t 단계가 약 1.5배)
- 자간: 20px 이상 제목은 -0.025em, 본문은 0.
- 굵기: 편안 400/500/600/700, 촘촘 400/600. (채널톡은 2종)
- 한국어는 `word-break: keep-all`로 낱말 중간에서 줄이 바뀌지 않게 한다.
- 숫자 열, 금액, 시각은 `tabular-nums`. (토스: 실시간 값은 고정폭 숫자)

## 간격

4px 단위만 쓴다: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64. (전부)

| 자리 | 값 |
|---|---|
| 모바일 화면 좌우 | 16~20 (당근 16, 토스 목록 20~24) |
| 목록 줄 안쪽 좌우 | 20~24 |
| 카드 묶음 사이 | 12~16 |
| 묶음 제목과 카드 사이 | 8 |
| 제목과 부제 사이 | 6~8 |
| 화면 아래 여백(하단 버튼 없을 때) | 48~56 |

## 모서리

| 대상 | 편안 | 촘촘 |
|---|---|---|
| 배지 | 4 | 4 |
| 버튼, 입력 칸 | 10 | 7 |
| 카드 | 16 | 10 |
| 시트, 대화상자 | 20 | 14 |

작은 것일수록 작게 한다. 버튼보다 카드가, 카드보다 시트가 둥글다. (LINE 3/5/7/12, 당근 2~24)
브랜드 개성에서는 전부 0(각지게, 29CM 방식)이나 버튼 완전 둥글게 중 하나를 고를 수 있다.

## 그림자

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--shadow-1` | 0 1px 4px 6% | 떠 있는 작은 단추 |
| `--shadow-2` | 0 4px 16px 8% | 메뉴, 토스트 |
| `--shadow-3` | 0 12px 32px 12% | 시트, 대화상자 |

카드에는 그림자를 넣지 않는다. 회색 바탕 위 흰 면이면 충분하다. (당근 s1~s3, 원티드, LINE)

## 움직임

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--dur-fast` | 150ms | 누름, 색 바뀜 |
| `--dur` | 250ms | 펼침, 탭 전환 |
| `--dur-slow` | 400ms | 시트, 화면 전환 |
| `--ease-enter` | (0, 0, .15, 1) | 들어올 때 |
| `--ease-exit` | (.35, 0, 1, 1) | 나갈 때 |

- 누르면 살짝 줄어든다(`.pressable`, 0.97). 당근 공식은 세로 2px만큼. 로딩, 비활성일 때는 줄지 않는다.
- `prefers-reduced-motion`이면 움직임을 끈다.
- 장식용 반복 애니메이션은 넣지 않는다.

## 접근성 기준

- 글자 대비 4.5:1 이상. 큰 글자(24px 이상 또는 19px 굵게)는 3:1.
- 터치 영역 44px. 보이는 크기가 작아도 누르는 영역은 44px.
- 아이콘만 있는 버튼은 `aria-label`.
- 색만으로 구분하지 않는다. 상태에는 글자나 아이콘을 함께.
- 포커스 테두리를 지우지 않는다.
