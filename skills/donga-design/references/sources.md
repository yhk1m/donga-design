# 근거와 출처 (2026-11-15 조사)

규칙은 10곳 중 여러 곳에서 겹치는 것만 넣었다. 수치는 공식 문서나 공개 저장소에서 확인한 값이다. 배민, 29CM, 카카오페이의 색 값은 비공식 자료뿐이라 규칙에 쓰지 않았다.

## 규칙별 근거

| 규칙 | 근거 회사 |
|---|---|
| 배우지 않아도 이해, 3초 안에 목적 | 토스 Simplicity, 당근 문화 가치, LINE Clear primary tasks, 쏘카 출시 점검표 |
| 한 화면 목표 하나, 주요 버튼 하나 | 토스 One Thing, 쏘카 Primary Goal, LINE, 당근 |
| 여백으로 나누고 선 줄이기 | 토스뱅크 디자인 리드 인터뷰, 배민, 29CM |
| 결과 예측, 위험 행동 확인 | 토스, 쏘카, LINE |
| 사용자 개념대로 묶기 | 토스뱅크, LINE "WE ≠ USERS" |
| 빈 화면과 오류 설계 | 쏘카, 원티드 Fallback view, LINE |
| 남색 기운 회색, 순수 검정 금지 | 토스, 당근, 쏘카, 원티드, LINE |
| 회색 바탕 위 흰 면 | 토스, 당근, 쏘카, 원티드 |
| 역할 이름으로 색 쓰기 | 모든 시스템 |
| 다크 모드 따로 설계, 위층일수록 밝게 | 토스, 당근, 쏘카, 채널톡 |
| 4px 간격 | 전부 |
| 작은 것일수록 작은 모서리 | LINE, 당근 |
| 옅은 그림자, 떠 있는 것에만 | 당근, LINE, 원티드 |
| 움직임 150/250/400ms, 감속 곡선 | 당근, 채널톡, 원티드 |
| 누르면 살짝 줄어듦 | 당근 |
| 대비 4.5:1, 터치 44px | LINE, 쏘카, 당근, 29CM |
| 버튼 위계 4단계, 하단 고정 버튼 | 토스, 쏘카, 원티드, LINE |
| 대화상자 "닫기" | 토스 |
| 토스트 한 번에 하나, 버튼 없음 | LINE, 원티드 |
| 로딩 시간별 기준 | 당근, 원티드, 토스 |
| 해요체, 과한 존칭 금지 | 토스, 당근 |
| 버튼은 결과와 목적 | 당근, LINE, 쏘카, 원티드 |
| 유머는 홍보 영역에만 | 배민 2.0 |
| 촘촘 모드 굵기 2종 | 채널톡 |
| 브랜드 개성(제목 서체, 모서리 0) | 배민, 29CM, 카카오페이 |
